# ApplyFlow — Design System

## Product Identity

ApplyFlow is a calm, modern, and focused workspace
for managing job applications.

The interface should feel professional,
distinctive, intuitive, and trustworthy.

## Design Direction

Editorial Productivity + Career Journey

Avoid generic AI-generated SaaS aesthetics.

## Color Palette

- Background: #F8F7F4
- Surface: #FFFFFF
- Primary: #235B4E
- Accent: #D58B55
- Text: #202824
- Border: #E4E6E1

Check accessible contrast ratios.

## Typography

- Headings: Manrope
- Body: Inter
- Clear typographic hierarchy
- Consistent font weights and line heights

## Layout Principles

- Prioritize meaningful information hierarchy.
- Use purposeful whitespace.
- Avoid unnecessary dashboard cards.
- Keep important actions prominent.
- Maintain consistent spacing.
- Use responsive layouts.

## Key UI Components

- Application Kanban board
- Application timeline
- Search and filter controls
- Application detail panel
- Contextual action menus
- Status indicators
- Clear empty and loading states

## UX Requirements

- Keyboard-accessible controls
- Visible focus states
- Accessible form validation
- Responsive desktop and mobile views
- Reduced-motion support
- Helpful error messages

## Avoid

- Excessive purple or blue gradients
- Generic four-stat-card dashboards
- Excessive shadows
- Decorative charts without purpose
- Unnecessary glassmorphism
- Random component styling
- Overly complex navigation

## Design Workflow

Before implementing major pages:

1. Identify the primary user goal.
2. Propose the information hierarchy.
3. Define desktop and mobile layouts.
4. Identify reusable components.
5. Review accessibility concerns.
6. Implement and visually review the page.
